# Demo script: Phase 1a

Run on the GitHub Pages deployment after Phase 0 and provisioning.

1. Open the site in a private window. Only the sign-in screen appears. No data, no menu.
2. Sign in as a founder (MFA prompt). Choose your name when asked.
3. Admin, Dry run: the plan is empty because lists already exist. Press Apply: no changes.
4. Quick add: press `n`, type `Call fictional vendor`, press Enter. It lands in Inbox (Board view).
5. Open it, set Status to Next without a contribution type: the app explains why not. Choose Operations, save.
6. Set a due date of today and priority P0. Open Today: it appears first.
7. Create a task with recurrence `weekly:MO`, mark it done: the next one appears.
8. Open Alerts: overdue and waiting items show. Snooze one for 1 hour: it disappears.
9. Open a task, History tab: versions list who changed what.
10. Try saving a note containing `$50,000`: the app refuses and points to SharePoint Documents.
11. Sign in with a non-founder tenant account in another browser: Access denied.
12. Open Microsoft Lists on the same site: all records are visible and editable there (fallback).
